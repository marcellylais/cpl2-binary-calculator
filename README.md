# 🔢 Calculadora Aritmética Binária (Complemento a 2)

Repositório desenvolvido para o trabalho prático da disciplina de **Introdução a Sistemas Digitais (ISD)**.

O programa executa operações matemáticas de **soma** e **subtração** com números binários de **8 bits**, realizando conversões automáticas para a base **decimal** e **hexadecimal**, utilizando o conceito de **Complemento a 2** para operações com números negativos.

---

## 📌 Funcionalidades

- 🔄 **Conversão de Bases:**
  - Binário para Hexadecimal (`binprahex`)
  - Binário para Decimal (`binpradec`)
- ➕ **Aritmética Binária:**
  - Soma de números binários bit a bit com controle de carry (`soma`)
  - Subtração e representação de números negativos utilizando **Complemento a 2** (`cpl2`)
- 📊 **Saída Formatada:** Exibição detalhada de cada passo das operações e do resultado final nas três bases (binário, decimal e hexadecimal).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem C** 💻
- **Biblioteca Padrão:** `stdio.h`, `stdlib.h`, `string.h`
